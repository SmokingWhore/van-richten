# Печать Ван Рихтена — интерактивная загадка

Небольшое автономное веб-приложение для загадки у двери башни Ван Рихтена в кампании «Проклятый старый дом».

## Запуск локально

Откройте `index.html` в современном браузере. Внешние библиотеки, сервер и отдельные файлы изображений не требуются: арты двери и камней встроены в HTML.

## Публикация через GitHub Pages

1. Создайте новый GitHub-репозиторий.
2. Загрузите в корень репозитория `index.html`, `README.md` и `.nojekyll`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После публикации GitHub Pages покажет адрес сайта в разделе Pages.

## Управление

- Коснитесь/нажмите на каждый из четырёх камней, чтобы переключать символы.
- Нажмите **«Дать ответ»** для проверки комбинации.
- При ошибке срабатывает звуковая ловушка, а диски автоматически возвращаются в исходное положение.
- При правильной комбинации дверь открывается с анимацией.

Звуковые эффекты синтезируются средствами браузера. На iPhone звук может начать воспроизводиться после первого пользовательского касания — это ограничение мобильного Safari.

## Загадка

> Сперва взойдёт без солнца бледный страж,  
> Затем из тьмы поднимет морду голод,  
> За ним проснётся тот, кто видит ложь,  
> И замолчит лишь тот, кто холоднее смерти.

## Для ведущего

Правильная последовательность: **Луна → Волк → Глаз → Серебро**.
